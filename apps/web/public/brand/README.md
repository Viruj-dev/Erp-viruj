# Viruj brand assets

Copied unchanged from the Viruj mobile app:
- `viruj-icon.png`: `Viruj-Mobile-app/apps/mobile/assets/icon.png` (primary app mark)
- `viruj-logo.png`: `Viruj-Mobile-app/apps/mobile/assets/auth/virujlogo.png` (authentication artwork)
- `src/app/icon.png`: mobile `assets/favicon.png`

Brand/contact configuration lives in `src/lib/viruj-brand.ts`. Its sources are the mobile app's `app.json`, `src/product/legal.tsx`, `api.ts`, and `web-pages.ts`. These assets retain their original colors; ERP workspace palettes are independent.
